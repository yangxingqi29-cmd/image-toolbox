# 功能与阶段状态

## 已完成

- 阶段 1：双语路由、首页、导航、主题、响应式设计。
- 阶段 2：文件签名校验、解码、预览、内存限制、取消和资源释放。
- 阶段 3：批量压缩、格式转换、尺寸调整、交互裁剪、ZIP 下载。
- 阶段 4：证件照尺寸、背景、人物位置、本地 MODNet 抠图、四套透明正装、JPG/PNG 导出。
- 阶段 5：文字/图片水印、平铺、批处理、图片排序、PDF 页面设置与导出。
- 阶段 6：静态 HTML、独立元数据、FAQ 结构化数据、hreflang、sitemap、robots、广告和同意组件预留。

## 构建时 SEO 配置

`VITE_SITE_URL` 必须设置为真实生产站点源地址。未设置时：

- 仍生成 24 个中英文静态页面和 `sitemap.xml`；
- 不输出可能错误的 canonical、hreflang 绝对地址；
- sitemap 保持空 URL 集并写入配置提示。

设置真实地址后重新执行 `npm run build`，生成器会写入 canonical、hreflang、Open Graph URL 和完整 sitemap。

## 广告

广告默认禁用。只有同时配置 `VITE_ADSENSE_ENABLED=true`、客户 ID、广告位 ID，并且用户允许广告 Cookie 后，页面才会请求 AdSense 脚本。广告区域位于工具操作区下方的教程内容之间。

## 已知限制

- PNG 无损重编码不保证减小体积。
- 生成前显示布局示意，生成后显示实际 PDF 预览；部分手机浏览器可能不支持内嵌 PDF，但可下载查看。
- 浏览器可能限制短时间内的多个独立下载，建议批量结果使用 ZIP。
- 手机浏览器进入后台时可能暂停 AI 或批量处理。
- 证件照尚未包含自动人脸定位、六寸冲印排版和指定文件大小压缩。

证件照服装为本项目通过内置图像生成工具制作的原创透明图层，保存于 `public/outfits/`。服装只覆盖肩部与上身，不修改五官；用户可调整大小和上下位置。
